# 公開前・旅行前チェックリスト

## 開発者が行う確認

Node.js 24環境で実行します。

```bash
nvm use
npm ci
npm audit --audit-level=moderate
npm run lint
npm run build
npm run preview
```

`npm audit`がmoderate以上を報告した場合は、公開を止めて依存更新の内容を確認します。

## GitHub Pages公開

- [ ] `.github/workflows/deploy.yml`がリポジトリに含まれている

## 旅行前の内容確認

- [ ] 2026年8月30日・31日の日付と曜日が正しい
- [ ] 舞台の会場名・開演時刻・集合方法を家族内で確認した
- [ ] Google Mapsの施設名が当日の目的地と一致している
- [ ] 交通機関の運休・遅延・臨時変更を前日に確認する
- [ ] 食事場所や予約が必要な予定は別途確定している
- [ ] 公開URLを家族へ共有した

## 変更時の注意

旅程の変更は`src/data/trip.ts`を編集し、変更後にlint・buildを再実行します。公開済みURLは静的ファイルの更新後、ブラウザのキャッシュやservice workerの影響で古い表示が残ることがあるため、変更確認時は再読み込みまたは別ブラウザでも確認します。
