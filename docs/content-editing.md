# 旅程データの編集ガイド

## 編集するファイル

通常の旅行差し替えでは [`src/data/trip.ts`](../src/data/trip.ts) だけを編集します。

画面側の`App.tsx`へ予定を追加する必要はありません。予定は`TripDay.stops`へ追加すると、時系列カードとして自動表示されます。

## 予定の基本形

```ts
{
  id: 'unique-stop-id',
  time: '10:00頃',
  title: '場所・予定名',
  place: '地図に表示する補足名',
  description: '利用者が読む短い説明。',
  transport: '徒歩 / 電車 / 会場内',
  kind: 'sightseeing',
  flexible: true,
  map: mapLinks('Google Mapsで検索する場所', '前の場所'),
  note: '必要な注意事項',
}
```

## 各フィールド

| フィールド | 必須 | 内容 |
|---|---:|---|
| `id` | 必須 | 旅程内で重複しない英数字の識別子 |
| `time` | 必須 | `10:00頃`、`午後`、`終演後`など利用者向け表示 |
| `title` | 必須 | カードの大見出し。短くする |
| `place` | 任意 | 場所の補足。Google Mapsの検索名と別でもよい |
| `description` | 必須 | 1〜2文の簡単な説明 |
| `transport` | 任意 | 次の移動や現在地までの移動方法 |
| `kind` | 必須 | `start` / `event` / `sightseeing` / `meal` / `transfer` / `finish` |
| `flexible` | 任意 | 時刻が目安の予定なら`true`。カードに「目安」と表示される |
| `map` | 任意 | 主要地点には`mapLinks()`で設定する |
| `note` | 任意 | 終演後・新幹線時刻未定などの注意事項 |

## 時刻の考え方

終演時間や帰りの新幹線のように固定できない情報は、推測した時刻を入れません。

- `終演後`
- `観光終了後`
- `午後`
- `夕方〜夜`

のような表記にし、必要なら`flexible: true`と`note`を併記します。

## Google Mapsリンク

```ts
map: mapLinks('長谷寺 鎌倉', '長谷駅（神奈川県）')
```

第1引数は目的地、第2引数は経路検索時の出発地です。検索結果が曖昧になりやすい場所は、「市区町村」や「駅名」を含めてください。

編集後は、次を確認します。

1. 場所名をGoogle Mapsで検索できる
2. 目的地と出発地の順番が合っている
3. 主要地点に「地図を見る」と「ここまでの経路」が出る
4. 外部リンクが新しいタブで開く

## 別の旅行へ差し替えるとき

1. `trip.title`と`trip.dateRange`を変更
2. `trip.days`に日付ごとの`TripDay`を設定
3. 各日の`routeLabel`を一方向の移動順で書く
4. `stops`を時間順に並べる
5. 地図リンク・時刻の柔軟性・注意事項を確認
6. READMEの旅行日と説明を更新

複数旅行を同時に管理する必要が出た場合は、`src/data/trips/`にデータファイルを分割し、選択する旅行をルートやビルド時設定で切り替える拡張が考えられます。MVPでは旅行データを1つに保ちます。
